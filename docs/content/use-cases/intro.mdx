Use cases are end-to-end demos that show the **AI Optimizer** working on a complete, realistic scenario. They pick up where the [Walkthrough](../walkthrough) leaves off.

:::danger[Keep it Clean!]
The demonstrations can change prompts, database objects, and vector stores as you experiment.
Run use cases in a clean demo environment, ideally the local environment created by the [Walkthrough](../walkthrough).
:::

Once you have:

- a chat model;
- an embedding model; and
- an Oracle AI Database configured,

a use case takes you from an ungrounded **Language Model** to one grounded in your own structured data (**NL2SQL**) and unstructured documents (**Vector Search**).

Each use case is self-contained; it lists the data and prompts it needs, the models it was tuned against, and example questions to ask at each step. However, you are encouraged to experiment with different models, different prompts, and a variety of questions.

:::note[New here?]
If you haven't set up the **AI Optimizer** yet, start with the [Walkthrough](../walkthrough). It installs a local environment you can reuse.
:::
