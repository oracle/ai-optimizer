The **AI Optimizer** acts as a proxy MCP server and can therefore interface with external MCP servers. When connected to an Oracle SQLcl MCP server instance, the **AI Optimizer** enables **Natural Language to SQL (NL2SQL)** capabilities.

This integration allows users to query structured data stored in an Oracle Database using natural language, without the need to write or execute SQL commands.
