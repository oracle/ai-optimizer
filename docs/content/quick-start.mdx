## Prerequisites

Every deployment requires a connection to [Oracle AI Database](./guides/database), including [Oracle AI Database Free](https://www.oracle.com/database/free/). The local client and all-in-one container provide a setup page for configuring this connection.

Install the tool required by your deployment path:

- [uv](https://docs.astral.sh/uv/getting-started/installation/) for bare-metal installation
- A container runtime, such as Docker or Podman, for container installation

The features you use determine the remaining requirements:

| Feature                 | Requirement                                                                                                     |
| ----------------------- | --------------------------------------------------------------------------------------------------------------- |
| Agents and flows        | Access to a [language model](./guides/ai-models#language-models)                                                |
| Vector Search           | Access to an [embedding model](./guides/ai-models#embedding-models)                                             |
| NL2SQL                  | [SQLcl](./guides/sqlcl-mcp-server) installed where the Server runs and available on `PATH`                      |

The all-in-one container includes SQLcl. Language and embedding models can use third-party APIs or run on premises.

<sub>*Oracle recommends running on-premises models on hardware with GPUs.</sub>

### Bare-Metal Installation

To run the **AI Optimizer** on bare-metal:

1. <ReleaseSourceExtract />

1. Create the project environment and install the application:

   ```bash
   uv sync --all-extras
   ```

1. _(Optional)_ Create an [environment file](./guides/env-vars) to pre-configure the application:

   ```bash
   cp src/.env.example src/.env.dev
   ```

   Edit `src/.env.dev` as needed. You can supply the required Oracle AI Database connection in this file or enter it on the local setup page for the current client process. See [Environment Variables](./guides/env-vars) for details.

1. Start the application:

   ```bash
   uv run python src/entrypoint.py client
   ```

1. Navigate to `http://localhost:8501`.

1. [Configure](./client/configuration) the **AI Optimizer**.

### Container Installation

To run the **AI Optimizer** in a container, use the following `podman` commands. You can substitute `docker` for `podman`.

3. Start the container:

   ```bash
   podman run -v ai-optimizer-data:/app/data -p 8501:8501 -it --rm localhost/ai-optimizer-aio:dev
   ```

1. Navigate to `http://localhost:8501`.

1. Complete the required Oracle AI Database setup page. A successful configuration is stored in the `ai-optimizer-data` container volume.

1. [Configure](./client/configuration) the **AI Optimizer**.

### Oracle Cloud Infrastructure

The included OpenTofu Infrastructure as Code (**IaC**) can deploy the **AI Optimizer** and its supporting infrastructure in Oracle Cloud Infrastructure (**OCI**). It can provision an Autonomous Database or connect the deployment to an existing Oracle database. See [Infrastructure as Code](./advanced-guides/iac) for deployment instructions.

### Kubernetes

The **AI Optimizer** can be deployed into a Kubernetes cluster using a Helm chart. For more information, see [Kubernetes / Helm](./advanced-guides/k8s-helm).
