Download and extract the latest release into a new directory:

**Latest Release**: [TAR.GZ archive](https://github.com/oracle/ai-optimizer/releases/latest/download/ai-optimizer-src.tar.gz)

For example:
```bash
curl -LO https://github.com/oracle/ai-optimizer/releases/latest/download/ai-optimizer-src.tar.gz
mkdir ai-optimizer
tar zxf ai-optimizer-src.tar.gz -C ai-optimizer

cd ai-optimizer
```
