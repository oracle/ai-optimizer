The **Oracle AI Optimizer and Toolkit** (the **AI Optimizer**) is an open-source platform for building, testing, and evaluating GenAI applications. Its agentic runtime grounds model responses at request time in authoritative private and sensitive data that remains outside the model's training knowledge and under your control in Oracle AI Database.

## What You Can Do

- Run LLM-only and tool-enabled [agents and flows](./advanced-guides/agents/intro).
- Ground responses in unstructured content by [splitting and embedding documents](./client/tools/split-embed) for Vector Search.
- Query structured data in Oracle AI Database through the [NL2SQL agent](./client/chatbot#nl2sql-natural-language-to-sql).
- Compare models, prompts, parameters, and retrieval settings in the [Chatbot](./client/chatbot).
- Evaluate configurations against generated or existing Q&A datasets in the [Testbed](./client/testbed).
- Apply identity-aware database authorization with [Oracle Deep Data Security](./client/tools/dds).
- Connect external applications through the [REST API](./server/api-examples/intro) or [MCP endpoint](./guides/mcp-clients).

## Architecture

The [**AI Optimizer Server**](./server/intro) hosts the REST API, agent and flow runtime, and MCP endpoint. The optional [**AI Optimizer Client**](./client/intro) provides a web interface for configuring and exercising the Server through its REST API. Other applications can integrate with the Server through the REST API or MCP endpoint.

```mermaid
flowchart LR
    web["AI Optimizer Client"] --> api
    rest["REST clients"] --> api
    mcpClients["MCP clients"] --> mcp

    subgraph server["AI Optimizer Server"]
        api["REST API"] --> runtime["Agent and flow runtime"]
        runtime --> mcp["MCP tools and prompts"]
    end

    runtime --> models["Language and embedding models"]
    runtime --> database["Oracle AI Database"]
    mcp --> database
    mcp --> sqlcl["SQLcl MCP Server"]
```

## Requirements

The Server requires an [Oracle AI Database connection](./guides/database) for application configuration and persistence. The routes you run determine the remaining requirements:

- A [language model](./guides/ai-models#language-models) runs agents and flows.
- An [embedding model](./guides/ai-models#embedding-models) creates vectors for RAG and Vector Search.
- [SQLcl](./guides/sqlcl-mcp-server) must be installed where the Server runs and available on `PATH` to use NL2SQL.

The client can run alongside the Server or connect to a separately deployed Server. All components can be colocated or distributed across local, on-premises, and cloud environments.
