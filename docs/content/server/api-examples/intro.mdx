The **AI Optimizer Server** exposes server capabilities through REST endpoints. Use the built-in Swagger UI at `/v1/docs` for the complete API reference.

Protected API requests require an Oracle database or OIDC bearer token. [Obtain a bearer token](../../guides/access-control#obtain-a-bearer-token) before running an authenticated example. The `/v1/liveness`, `/v1/readiness`, and `/v1/healthz` health-probe endpoints are public.

:::
