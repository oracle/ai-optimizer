One **AI Optimizer Server** can serve many web clients, IDEs, MCP clients, and external applications. Each authenticated account has its own workspace.

## Working on a Shared Server

| Shared configuration | Per-account workspace |
|---|---|
| Database connections and vector stores | Conversation history |
| Model configurations and API credentials | Selected database, language model, and OCI profile |
| OCI profiles | Enabled tools and Vector Search settings |
| Prompt configurations | Language model parameters and Testbed model selections |

Members can select different databases and tools. Admin changes to shared configuration are available to every account.

The [Racing Championship](../use-cases/racing) use case applies this model: each participant chooses a different driver while the group shares the prepared database and document collection.

## API sessions

[Obtain a bearer token](../guides/access-control#obtain-a-bearer-token), then send it with each request:

```shell
curl -X POST https://localhost:8000/v1/chat/completions \
  -H "Authorization: Bearer $AIO_BEARER_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"messages": [{"role": "user", "content": "Hello"}]}'
```

See [Access Control](../guides/access-control) for authorization.
